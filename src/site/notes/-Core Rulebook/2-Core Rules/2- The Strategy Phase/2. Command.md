[[-Core Rulebook/2-Core Rules/2- The Strategy Phase/1. Start Of Turn\|1. Start Of Turn]]

---
During this sub-phase, powerful abilities, both magical and
mundane, are unleashed in the form of [[-Core Rulebook/3-Advanced Rules/1-Special Rules/What Are Special Rules？\|special rules]].

The [[-Core Rulebook/2-Core Rules/1- The Turn Sequence/A Game Of Rounds & Turns#Active & Inactive Player\|active player]] chooses one of their models (usually a character) that is not fleeing and that has one or more special rules that can be used during the Command sub-phase. The player states which special rule (if any) they intend to use and, if necessary, which unit(s) will be affected, before making any [[-Core Rulebook/1-Overview of the Game/2-Model Profiles/Characteristic Tests\|tests]] required. The active player then repeats the process for all models in their army that have any special rules that can be used during the Command sub-phase.

*Note that, unless stated otherwise, 
a model can only use a special rule once per Command sub-phase.*
