A unit arrayed in serried ranks is said to be in a ‘Close Order’ formation. A unit in Close Order consists of two or more models that are arranged in base contact with each other, edge-to-edge and front corner to front corner, as shown in [this diagram](/img/user/Images/Diagrams/Forming%20Units%20Fig%20100.1.png).

All models in such a unit must face the same direction. In addition, the models must be arranged into a formation that consists of one or more horizontal rows called ranks, and a number of vertical rows called files (from this formation comes the term ‘rank and file’).

As far as possible, there must be the same number of models in each rank. Where this is not possible, it must be the rear rank that has fewer models. Once formed into a unit, the models move and fight as a single entity for the entire battle.

---
#### Unit Shape
The shape of a unit in Close Order is also important as such units gain bonuses in certain situations. Based upon this, such units can be said to be in ‘Combat Order’ or in ‘Marching Column’.
#### Combat Order
A Close Order formation that is wider than it is deep (i.e., that has more models per rank than per file, as shown in [Fig 101.1](/img/user/Images/Diagrams/Close%20Order%20Fig%20101.1%20101.2.png)) or that is square (i.e., has the same number of models per file as per rank) is said to be in Combat Order. Such units are able to count a ‘Rank Bonus’ in certain situations:

**Rank Bonus:** If a unit in Close Order formation is wide enough, it can claim a Rank Bonus of +1 for each rank behind the first, up to the maximum determined by its troop type:
{ #c05e40}

	- How many models a rank must contain to claim a Rank Bonus, as well as the maximum Rank Bonus a unit can claim, is determined by its troop type (see [[-Core Rulebook/1-Overview of the Game/6-Troop Types At A Glance/Troop Type Table\|Troop Type Table]] and [[-Core Rulebook/3-Advanced Rules/3-Troop Types In Detail/Troop Types in Detail\|Troop Type Tables]]).
	- Certain special rules may increase the Rank Bonus a unit can claim beyond the maximum normally allowed by its troop type (see [[-Core Rulebook/1-Overview of the Game/6-Troop Types At A Glance/Troop Type Table\|Troop Type Table]]).
{ #e6ae6e}


*Note that this bonus can be claimed for an incomplete rear rank, as long as there are sufficient models in it. However, if your unit has become [[-Core Rulebook/1-Overview of the Game/3-Forming Units/Disrupted Units\|Disrupted]] it cannot claim a Rank Bonus.*

**Combat Result Bonus:** Whilst in Combat Order, a Close Order formation with a Unit Strength of 10 or more may claim a bonus of +1 combat result point (see page 151)
#### Marching Column
A unit that is deeper than it is wide (i.e., that has more models per file than per rank, as shown in [Fig 101.2](/img/user/Images/Diagrams/Close%20Order%20Fig%20101.1%20101.2.png)) is said to be in Marching Column. A Marching Column cannot claim a Rank Bonus and cannot make a charge move, but may triple its [[-Core Rulebook/1-Overview of the Game/2-Model Profiles/Model Profiles#Movement (M)\|Movement]] characteristic when [[-Core Rulebook/2-Core Rules/4- Movement in Detail/Basic Movement#Marching\|Marching]].
